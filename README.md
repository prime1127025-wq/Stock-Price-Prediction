# 📈 Stock Price Prediction Using Machine Learning

## 📌 Project Overview

This project predicts stock prices using historical stock market data and machine learning/deep learning techniques. It retrieves historical stock data using Yahoo Finance and visualizes price trends through interactive charts.

The project aims to demonstrate how historical market data can be processed, visualized, and used to train predictive models.

## 🎯 Objectives

- Retrieve historical stock market data using Yahoo Finance.
- Analyze historical stock price trends.
- Visualize stock prices using interactive charts.
- Apply machine learning or deep learning techniques to predict stock prices.
- Build an interactive web application using Streamlit.

## 🛠️ Technologies Used

- **Python** – Programming language
- **Streamlit** – Interactive web application
- **YFinance** – Historical stock market data
- **Pandas & NumPy** – Data processing and numerical calculations
- **Plotly** – Interactive data visualization
- **Scikit-learn** – Machine learning tools
- **TensorFlow & Keras** – Deep learning and neural networks

## ✨ Features

- Fetch historical stock market data.
- Display historical stock prices through interactive graphs.
- Analyze stock price movements over time.
- Generate model-based price predictions.
- Provide a simple and user-friendly interface.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the project directory

```bash
cd stock-price-prediction
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```

The application will open in your browser, usually at `http://localhost:8501`.

## 🚀 Deployment

The application can be deployed using Streamlit Community Cloud by connecting the GitHub repository and selecting `app.py` as the application entry point.
